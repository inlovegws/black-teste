# Voice Frequency Analyzer

## Como acessar localmente
- Caminho absoluto do arquivo principal: `/workspace/black-teste/index.html`.
- Abra esse arquivo no navegador para usar a seção "Voice frequency analyzer".
- O script de análise de áudio está em `js/voice-analyzer.js`.

Se quiser servir via HTTP, execute `python -m http.server 8000` no diretório do projeto e acesse `http://localhost:8000/`.
